# Documentação do Nauren RPG (sistema para Foundry VTT)

## Para jogar e mestrar
| Arquivo | O que é |
|---|---|
| `hud-combate.md` | O painel de Ações embaixo da tela: quando aparece, atalhos e o que cada botão faz. |
| `reacao-em-dois-passos.md` | Como a reação a um ataque funciona no sistema (reagir e depois resolver). |
| `animacoes.md` | Como ligar o Automated Animations, o Sequencer e o JB2A, e quais nomes cadastrar. |
| `nauren-aa-menu-completo.json` | O menu completo de animações e sons do Nauren, para importar no Automated Animations. |
| `nauren-aa-novas-0.94.27.json` | Só as animações novas desde a 0.92.2 (importar com Merge). |
| `sons-forge.txt` | Os sons da mesa, com o endereço completo de cada um. |

## Para criar fichas e animações com IA
| Arquivo | O que é |
|---|---|
| `guia-criacao-ia.md` | Guia completo do formato das fichas (JSON) para uma IA criar criaturas, itens e habilidades. |
| `prompt-criacao-criatura.md` | Prompt pronto para criar uma criatura, com a tabela de valores por nível. |
| `modelo-ficha-codex.xlsx` | Modelo da ficha em planilha (Códex), com exemplos e instruções para IA. |
| `icones-foundry.txt` | Lista de todos os ícones do Foundry; a IA só pode usar caminhos que estejam aqui. |
| `guia-animacoes-ia.md` | Guia para a IA montar o JSON de animações de uma criatura (Automated Animations). |
| `aa-modelos-entradas.json` | Modelos de entrada do Automated Animations usados pelo guia acima. |
| `jb2a-catalogo.md` | Resumo das animações do JB2A, com cores e exemplos. |
| `jb2a-caminhos.txt` | Todos os caminhos do JB2A; todo caminho usado no JSON de animações precisa existir aqui. |

## Integração com o bot da Torre Infinita
| Arquivo | O que é |
|---|---|
| `catalogo-torre-infinita.json` | Catálogo dos itens da Torre (chaves, tiers, pigmentos), no formato que o bot O Curador lê. |
