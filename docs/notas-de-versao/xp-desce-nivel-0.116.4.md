# 0.116.4 — Diminuir o XP desce o nível

- Na ficha de personagem, se o XP total ficar abaixo do mínimo do nível atual, o **nível desce junto** para o nível que esse XP alcança (ex.: nível 5 com 1.400 XP → mudar para 600 XP → nível 3).
- Descer assim usa o mesmo caminho de "descer de nível": o que a Classe deu nos níveis perdidos é desfeito.
- Subir continua pelo botão **Subir de Nível** (aumentar o XP não sobe o nível sozinho, porque subir tem escolhas).
- NPCs não mudam (o nível deles é do Mestre).
