# 0.121.1 — Poesia Ghurua: "início de cada turno" é todo turno

- **Chuva Infinita**: aliados na área recuperam 1d6 de Vida no início de **cada turno**, de qualquer combatente (antes, só no turno deles).
- **Aroma de Licor**: +1 Energia no início de **cada turno**, de qualquer combatente.
- As Condições já aplicadas no mundo são atualizadas sozinhas, porque o compêndio é ressemeado ao abrir o mundo. Uma Poesia que já estava ativa segue com a regra antiga até acabar (1 rodada).
