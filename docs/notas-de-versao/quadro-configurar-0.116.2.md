# 0.116.2 — Quadro: Configurar rola de novo e ícone no mapa

- A aba **Configurar** (e Registro) da ficha do Armazenamento no modo Quadro voltou a rolar: só a aba Quadro fica sem rolagem própria (o quadro tem zoom e arrastar).
- No modo Quadro, Configurar mostra só o que vale para o quadro: some "Espaços", "Loja" e "Pode pegar/guardar" (que já aparecem como "Jogadores podem arrancar/pregar"). A "Frase no topo" foi para a caixa Quadro de avisos.
- Ícone novo para o ponto no mapa: **Quadro de avisos** (placa de madeira). Ao virar Quadro, um armazenamento que ainda usava o ícone de baú passa para ele.
- **Colocar no mapa**: Configurar → caixa "No mapa" → botão **Colocar no mapa** e clique no lugar da cena (Esc cancela). Funciona igual ao baú e à loja.
